MNIST CNN 실험 보고서

손글씨 숫자 인식 CNN 모델 분석

1. 실험 개요

CNN(합성곱 신경망)을 이용하여 MNIST 손글씨 데이터를 학습시키고, 숫자의 형태 및 위치 변화에 따른 인식 결과를 분석하였다.

2. 학습 곡선

학습 과정에서 Loss 값은 점점 감소하며 모델이 점점 정확해지는 것을 확인할 수 있었다. 하지만 중간에 값이 튀는 구간도 존재하며, 이는 학습 과정의 불안정성을 보여준다.

  • Loss: 모델이 얼마나 틀렸는지를 나타냄
  • 초반에는 크게 감소, 이후 점점 안정됨
  • 완전히 0이 되지 않는 것은 일반화 때문

3. 직접 입력 테스트

직접 그린 숫자를 입력한 결과, 모델은 7을 98.1% 확률로 예측하였다. 이는 특정 형태의 특징에 강하게 반응하는 것을 의미한다.

4. 위치에 따른 인식 변화

같은 숫자라도 위치(왼쪽, 중앙, 오른쪽)에 따라 인식 결과가 달라졌다. 특히 숫자 1은 위치에 따라 다른 숫자로 잘못 인식되는 경우가 많았다.

5. 반복 학습과 과적합

같은 데이터를 반복 학습시키면 정확도가 올라가다가 다시 떨어지는 현상이 발생하였다. 이는 모델이 데이터를 외워버리는 과적합(overfitting) 때문이며, 새로운 데이터에 대한 성능이 감소한다.

6. 결론

CNN 모델은 대부분의 숫자를 잘 구분하지만, 형태가 비슷한 숫자(1, 5, 7)와 위치 변화에는 약한 모습을 보였다. 또한 과적합을 방지하기 위해 적절한 학습 횟수가 중요하다.
