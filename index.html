MNIST CNN 실험 보고서

손글씨 숫자 인식 CNN 모델 분석

1. 실험 개요

CNN(합성곱 신경망)을 이용하여 MNIST 손글씨 데이터를 학습시키고, 숫자의 형태와 위치 변화에 따른 인식 성능을 분석하였다.

2. 학습 곡선 분석

학습이 진행될수록 Loss 값은 감소하며 모델의 성능이 향상되는 것을 확인할 수 있었다. 그러나 학습이 계속될수록 값이 다시 증가하는 구간도 나타났으며, 이는 과적합의 가능성을 보여준다.

3. 데이터 특징

MNIST 데이터는 다양한 사람이 작성한 손글씨로 구성되어 있어 같은 숫자라도 모양이 다르게 나타난다. 특히 1, 5, 7과 같은 숫자는 형태가 유사하여 모델이 혼동하는 경우가 많았다.

4. 위치에 따른 인식 변화

같은 숫자라도 이미지 내 위치(왼쪽, 중앙, 오른쪽)에 따라 모델의 인식 결과가 달라지는 것을 확인하였다. 특히 숫자 1은 위치 변화에 따라 인식 결과가 크게 달라졌다.

5. 반복 학습과 과적합

동일한 데이터를 반복적으로 학습시키면 정확도가 증가하다가 다시 감소하는 현상이 나타났다. 이는 모델이 데이터를 일반화하지 못하고 특정 데이터에 과하게 맞춰지는 과적합(overfitting) 현상 때문이다.

6. 결론

CNN 모델은 전반적으로 높은 정확도를 보였지만, 손글씨의 다양성과 위치 변화에는 영향을 받았다. 또한 적절한 학습 횟수를 유지하지 않으면 과적합이 발생할 수 있으므로 학습 조절이 중요하다.
